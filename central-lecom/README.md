# Central LECOM

Site estático de referência sobre uso e documentação de processos LECOM.

## Abrir localmente

Abra `index.html` em um navegador. A fonte Inter e os recursos visuais estão incluídos localmente; não é necessário instalar dependências nem ter conexão com a internet.

## Recursos

- Busca por conteúdo e filtros por coleção
- Favoritos e tema salvos neste navegador
- Links diretos para páginas, navegação responsiva

Este site é uma base de conhecimento estática; favoritos e preferências são locais ao navegador e não são compartilhados entre usuários.
